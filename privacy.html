Privacy policy

Hermes Agent · personal automation tool · last updated 2026-10-02

Scope

Hermes Agent is a private tool with exactly one user: its owner. It is not a service offered to the public, and it has no other accounts.

What is accessed

With the owner's explicit consent, the tool accesses data in the owner's own Google account: Google Drive files, Gmail messages, Calendar events, Sheets spreadsheets and Docs documents. It uses these only to perform tasks the owner asked for — for example, storing backups of the owner's own files in his own Drive, or reading a letter he asked about.

What is done with it

  • No data is sold, shared, published or transferred to any third party.
  • No advertising or profiling of any kind.
  • No data is collected about anyone other than the owner.

Where it is stored

On the owner's own computer. Access tokens are stored locally in an encrypted/session file owned by the user and are never transmitted anywhere except to Google's own API endpoints.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions. Deleting the stored token on the local machine achieves the same result immediately.
